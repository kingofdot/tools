# 서류 폼 입력 안내 – 2안(주황 박스 + 화살표) 구현 지침

VS Code에서 그대로 쓸 수 있게 정리한 스타일/렌더러/데이터 명세입니다.

```
annotate/handoff/
├─ README.md                 ← 이 문서
├─ annotation-guide.css      ← 스타일 (토큰 + 클래스)
├─ annotation-guide.js       ← 데이터 → HTML 렌더러 (의존성 없음)
├─ guide-data.json           ← 갑지 6개 섹션 실제 데이터 (좌표 포함)
└─ example.html              ← 최소 실행 예제
```
패널 이미지는 `annotate/handoff/img/` 에 함께 들어 있습니다(`sec.imgBase`로 경로 변경 가능).

---

## 1. 화면 구성 규칙

한 섹션 = 카드 1개. 카드 안은 **항목 2~3개 단위의 패널**로 쪼갭니다. 항목이 많은 섹션을 한 장에 몰아넣으면 화살표가 교차하므로, 쪼개는 것이 이 시안의 핵심입니다.

- **패널 이미지**: 섹션 스크린샷에서 그 패널의 항목들만 남도록 위아래를 잘라낸(crop) 이미지. 좌우는 자르지 않음.
- **박스**: 해당 입력창/버튼의 실제 경계에 맞춘 주황 사각형(2px, 반경 6px, 바깥 글로우 3px).
- **번호**: 세로 배치(side)는 박스 왼쪽 바깥, 가로 배치(below)는 박스 위쪽. 화면 요소를 절대 가리지 않게.
- **콜아웃**: 세로 배치는 이미지 우측, 가로 배치는 이미지 아래. 박스와 같은 높이(또는 같은 x)에 두어 화살표를 최단으로.
- **화살표**: 직선 세그먼트 조합. 꺾임은 최대 1회, 화살촉은 항상 **박스 쪽**을 향함.

### 두 가지 배치 모드
| mode | 언제 | 콜아웃 위치 | 이미지 폭 |
|---|---|---|---|
| `side` | 항목이 위→아래로 나열될 때 (입력 폼 대부분) | 이미지 우측 326px | 600px |
| `below` | 항목이 좌→우로 나열될 때 (상단 바, 하단 버튼 줄) | 이미지 아래, 레인 배치 226px | 940px |

## 3. 데이터 스키마 (`guide-data.json`)

```jsonc
{
  "key": "s2",                  // 섹션 id
  "id": "sec2-bizinfo.png",     // 섹션 전체 스크린샷 (1안에서 사용)
  "x0": 460, "y0": 665,         // 원본 업로드 이미지에서 이 섹션의 좌상단
  "cw": 810, "ch": 945,         // 섹션 좌표계 크기 (모든 박스 좌표의 기준)
  "step": "SECTION 02",
  "title": "사업장 정보",
  "sub": "선택한 서류에 공통으로 기재되는 정보입니다",
  "f": [                        // 항목(번호 순서 = 배열 순서)
    { "b": [24, 107, 754, 28], "title": "상호명", "desc": "사업자등록증에 기재된 상호를 그대로 입력하세요.",
      "x": 28, "y": 121 }       // x,y = 1안 배지 앵커(자동 계산: b[0]+4, b[1]+b[3]/2)
  ],
  "g": [                        // 패널(그룹)
    { "f": [0, 1],              // 이 패널에 들어갈 항목 인덱스
      "mode": "side",           // "side" | "below"
      "label": "상호 · 사업자 유형",
      "img": "grp-s2-1.png",
      "crop": [0, 93, 810, 117] // 섹션 좌표계에서 잘라낸 영역 [x,y,w,h]
    }
  ]
}
```

**좌표계 규칙**: `b`와 `crop`은 모두 *섹션 좌표계*(`cw × ch`) 값입니다. 렌더러가 `k = 이미지표시폭 / crop[2]`로 스케일하고 `crop`의 원점을 빼서 화면 좌표로 변환합니다. 스크린샷을 새로 찍어 해상도가 달라져도 `cw/ch`만 맞으면 좌표는 그대로 유효합니다.

## 4. 사용법

```html
<link rel="stylesheet" href="annotation-guide.css">
<script src="annotation-guide.js"></script>
<script>
  fetch('guide-data.json').then(r => r.json()).then(sections => {
    document.getElementById('root').innerHTML = sections
      .map(s => (s.imgBase = 'img/', renderGuideSection(s)))  // 이미지 경로 접두어
      .join('');
  });
</script>
```

React라면 렌더러의 문자열 대신 같은 계산식을 그대로 컴포넌트로 옮기면 됩니다. 계산 로직은 `annotation-guide.js`의 `sidePanel` / `belowPanel` 두 함수뿐입니다.

## 5. 새 화면을 추가할 때 (중요)

박스가 어긋나면 이 시안은 전부 무너집니다. **눈대중 금지**, 아래 순서로 좌표를 뽑으세요.

1. 폼 화면을 한 장으로 캡처하고, 섹션별로 좌우 폭을 통일해 잘라 `sec*.png`로 저장.
2. 섹션 이미지에서 입력창 경계를 **픽셀 스캔**으로 검출: 카드 배경(흰색)보다 어두운(평균 밝도 < 249) 픽셀이 이어지는 행/열을 찾으면 그것이 입력창 테두리입니다.

```js
// 브라우저/Node(canvas) 공통 아이디어 — 세로 스캔으로 입력창 상·하단 y를 얻는다
const S = img.width / cw;                    // 섹션 좌표 1 단위 = S 픽셀
const x = Math.round(600 * S);               // 입력창을 가로지르는 임의의 x
const dark = [];
for (let y = 0; y < img.height; y++) {
  const [r, g, b] = pixel(x, y);
  if ((r + g + b) / 3 < 249) dark.push(y / S); // 섹션 좌표로 환산
}
// dark를 연속 구간으로 묶으면 [상단테두리, 하단테두리] 쌍이 나온다 → b=[left, top, width, height]
```
3. 좌우 경계도 같은 방식으로 가로 스캔(카드 내부 여백 x=24, 우측 778 형태로 반복 검출됨).
4. 항목을 2~3개씩 묶어 `g`(패널)를 정의하고, `crop`은 `min(top) - 14` ~ `max(bottom) + 14`로 자릅니다(위아래 여백 14).
5. 패널 이미지를 그 crop으로 잘라 저장 → 렌더 → 육안 확인.

## 6. PNG로 내보낼 때

패널마다 `data-panel="s2-3"`, 섹션 카드에 `data-section="s2"`가 붙어 있습니다. 이 셀렉터로 요소 단위 캡처(2x)하면 문서/노션 업로드용 PNG가 나옵니다. 폭 기준: 섹션 카드 1010px × 2 = 2020px, 패널만 캡처하면 약 950~1000px × 2.

## 7. 문구 규칙

- 짧은 명령형(`~하세요`), 한 항목당 1~2문장.
- 가상 예시값은 넣지 않음(사용자 확정 사항).
- 제목은 화면의 라벨을 그대로 사용. 버튼·필드명은 `[대괄호]`로 표기.
