# 미리보기 갑지 최종본

`test.png`(실제 화면 전체 캡처)와 `갑지생성*.png` 를 소스로, **마커컷2 에서 확정한 문구**를 그대로 쓰고
주석 패널 스타일(`annotate/work`)로 만든 결과물이다.

- 규격·색·기하 전부: [`미리보기_파이널_지침.md`](../../../../미리보기_파이널_지침.md)
- 생성기: [`_build/gen_final.py`](../../../../_build/gen_final.py) · 결과물 컷은 [`_build/gallery.py`](../../../../_build/gallery.py)

```bash
cd "인허가 서대리_미리보기 페이지 작성"
python _build/gen_final.py          # 전량
python _build/gen_final.py 01 03    # 해당 섹션만
```

## 이 폴더에서만 다른 점 (지침 대비)

소스 화면이 1549 CSS 로 넓어 기본 카드(1010px)에 넣으면 글씨가 뭉갠다. 카드를 키웠다.

```python
CARD_W = 1440
SIDE   = dict(IW=940, GAP=26, CW=412, IX=0, CPL=43)
# 불변식: IW + GAP + CW == CARD_W - 62   (테두리 2 + 좌우 패딩 60)
```

나머지(색·박스·번호·지시선·콜아웃)는 지침 그대로다.

## 지침에 없던 항목 (여기서 추가한 것)

렌더러(`annotate/work`)와 생성기에 아래를 더했다. 전부 항목·패널 단위로 껐다 켤 수 있다.

| 이름 | 어디에 | 무엇 |
|---|---|---|
| `co` | 항목 | 콜아웃 쌓는 순서. 기본은 번호순. 나란히 놓인 박스에서 **왼쪽 것을 아래로 내려야** 그 지시선이 오른쪽 박스를 안 가로지른다. (03-1, 05-1, 06-2) |
| `dots` | 항목 | 박스 하나 안에서 여러 지점을 짚는 점. 선택지가 셋인 컨트롤에 칸마다 박스를 치면 시끄러워 점만 찍는다. (07-1) |
| `flow` | 섹션 | **패널을 가로지르는 흐름 화살표**. 실선 + 화살촉이라 점선 지시선과 구분된다. `{'from': 1, 'to': 2, 'text': '...'}` 로 박스 번호만 준다. (02) |
| `mask` | 패널 | 등록번호·주소·연락처 같은 값을 모자이크. 원본 PNG 는 안 건드리고 잘라 낸 패널에만 적용한다. (09-1) |
| `snap=False` | 항목 | 픽셀 스냅 생략. 여러 요소를 한 박스로 묶거나 배경이 투명한 탭은 스냅이 오히려 박스를 망친다. (06-1, 07-1, 08-1) |
| `ycrop` / `xcrop` | 패널 | 크롭을 직접 지정. 배경 행 스냅으로 못 잡는 화면과, 한쪽 컬럼만 쓸 때 반대편을 잘라 낼 때. |
| `pady` | 패널 | 크롭 여백(기본 40). |
| `gallery` | 섹션 | 박스·지시선 없이 만들어진 서류를 그리드로 늘어놓는 컷. (11) |

### 크롭은 넉넉하게

`PADY` 기본값을 16 → **40** 으로 올렸다. 좁게 주면 대상 위의 라벨(`표준산업분류코드`)이나
카드 테두리가 반토막 난다. `snap_edge()` 는 "거의 전부 배경인 행"만 후보로 삼는데
**카드 안쪽은 배경이 아니라서** 탐색 범위가 카드 바깥까지 닿아야 후보를 찾는다.
못 찾으면 지정한 위치에서 그냥 잘린다.

전 패널을 **머리(라벨·카드 헤더)가 보이는 범위**로 다시 잡았다.
빈 칸만 보여 주면 무엇을 넣는 칸인지 알 수 없으므로, 등록번호는 개인·법인 각각
값이 채워진 화면(`갑지생성4` · `갑지생성5`)을 나란히 놓았다.
