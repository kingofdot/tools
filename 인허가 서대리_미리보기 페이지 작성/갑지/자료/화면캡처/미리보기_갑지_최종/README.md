## 이 폴더에서만 다른 점 (지침 대비)

소스 화면이 1549 CSS 로 넓어 기본 카드(1010px)에 넣으면 글씨가 뭉갠다. 카드를 키웠다.

```python
CARD_W = 1440
SIDE   = dict(IW=940, GAP=26, CW=412, IX=0, CPL=43)
# 불변식: IW + GAP + CW == CARD_W - 62   (테두리 2 + 좌우 패딩 60)
```

나머지(색·박스·번호·지시선·콜아웃)는 지침 그대로다.

## 지침에 없던 개선 두 가지

1. **박스 좌표 자동 스냅** — 시드를 손으로 찍고 `_build_markers2.snap()` 으로 소스 PNG 위에서
   실제 요소 경계를 찾아 보정한다. 전 항목 이동량이 로그에 남는다(최대 dh +13px).
2. **crop 배경행 스냅** — 패널 위·아래를 "거의 전부 배경인 행"에 맞춘다.
   원본 handoff 의 `min(top)−14 ~ max(bottom)+14` 규칙에서 생기던 **반토막 행이 사라졌다.**
