## 카드 규격

STEP 컷과 섹션 카드는 서로 다른 스타일시트를 쓰지만 **테두리·그림자·폭을 맞춰 놓았다.**

| | STEP 컷 | 섹션 카드 |
|---|---|---|
| 스타일시트 | `annotate/work/annotation-guide.css` (`.ag`) | `_build/design.css` (`.sbox`) |
| 카드 폭 | 1440px | 1080px × zoom 1.333 |
| 테두리 | 1.5px `#C9D6EC` | 1.5px `#C9D6EC` |
| 모서리 | 20px | 26px |
| 그림자 | `0 18px 44px -22px rgba(20,45,110,.26)` | `0 26px 60px -24px rgba(20,45,110,.28)` |

```python
# gen_final.py
CARD_W = 1440
SIDE   = dict(IW=940, GAP=26, CW=412, IX=0, CPL=43)
# 불변식: IW + GAP + CW == CARD_W - 62   (테두리 2 + 좌우 패딩 60)
```

## 렌더러 기능

`annotate/work` 와 생성기에 더한 것들. 전부 항목·패널 단위로 껐다 켤 수 있다.

| 이름 | 어디에 | 무엇 |
|---|---|---|
| `co` | 항목 | 콜아웃 쌓는 순서. 나란한 박스에서 **왼쪽 것을 아래로 내려야** 지시선이 오른쪽 박스를 안 가로지른다. (03-1, 05-1, 06-2) |
| `dots` | 항목 | 박스 하나 안에서 여러 지점을 짚는 체크 표시. 선택지가 셋인 컨트롤에 칸마다 박스를 치면 시끄러울 때. (07-1) |
| `flow` | 섹션 | 패널을 가로지르는 흐름 화살표(실선 + 화살촉). 점선 지시선과 구분된다. `{'from': 1, 'to': 2, 'text': '...'}` (02) |
| `mask` | 패널 | 등록번호·주소·연락처 모자이크. 원본은 두고 잘라 낸 패널에만 적용. (09-1) |
| `snap=False` | 항목 | 픽셀 스냅 생략. 여러 요소를 한 박스로 묶거나 배경이 투명한 탭에 쓴다. |
| `ycrop` / `xcrop` | 패널 | 크롭 직접 지정. 배경 행 스냅으로 못 잡는 화면, 한쪽 컬럼만 쓸 때. |
| `pady` | 패널 | 크롭 여백(기본 40). |
| `gallery` | 섹션 | 박스·지시선 없이 서류를 그리드로 늘어놓는 컷. (11) |

### 크롭은 넉넉하게

`PADY` 기본값 40. 좁게 주면 대상 위 라벨이나 카드 테두리가 반토막 난다.
`snap_edge()` 는 "거의 전부 배경인 행"만 후보로 삼는데 **카드 안쪽은 배경이 아니라서**
탐색 범위가 카드 바깥까지 닿아야 후보를 찾는다. 못 찾으면 지정한 위치에서 그냥 잘린다.

전 패널을 **머리(라벨·카드 헤더)가 보이는 범위**로 잡았다. 빈 칸만 보여 주면 무엇을
넣는 칸인지 알 수 없으므로, 등록번호는 개인·법인 각각 값이 채워진 화면을 나란히 놓았다.

## 주의

- 원본 PNG(`test_컷/`, `갑지생성*.png`, `결과물/`)는 수정하지 않는다. 자른 결과만 새로 쓴다.
- `_build/*.html` 의 스타일시트는 **상대 경로**로 둔다. 빌더가 렌더 직전에 절대 경로로 바꾼다.
  절대 경로를 박아 두면 다른 PC 에서 스타일이 통째로 날아간다.
