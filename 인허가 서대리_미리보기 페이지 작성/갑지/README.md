# 갑지 만들기 · 이용가이드

인허가 서대리 「갑지 만들기」 서비스의 이용가이드. 구성은 **5단**이다.

| 단 | 내용 | 상태 |
|---|---|---|
| 01 | 개요 | 작성 |
| 02 | 필요서류 — 개인사업자 · 법인사업자 모두 **사업자등록증** | 작성 |
| 03 | 필요자료 — **없음** | 없음으로 표기 |
| 04 | 서류 작성 안내 — 서류 선택 → 사업장 정보 → 제출청·시점 → 검증·생성 (마커컷 12종) | 작성 |
| 05 | 결과물 | **아직 없음** (준비 중으로 표기) |

## 폴더

```
갑지/
  _guide_gapzi.html   가이드 원본
  _build_guide.py     렌더 스크립트
  갑지_이용가이드.png   결과 이미지 (3248 x 23351)
  자료/
    화면캡처/          서비스 화면 원본 캡처
      마커컷/          지시선-박스 마커를 얹은 12종 (가이드에 실제로 쓰이는 것)
  결과물/              생성된 갑지 예시 자리 — 아직 없음
```

## 다시 만들기

```
python _build_guide.py
```

`_guide_gapzi.html` 을 고친 뒤 위 명령만 돌리면 `갑지_이용가이드.png` 가 갱신된다.

**분할 렌더를 쓰는 이유** — Chrome 헤드리스는 큰 이미지가 여러 장 들어간 아주 긴 페이지를
한 번에 캡처하면 뒷부분을 통째로 누락시킨다(창 높이를 14000·16000으로 올려도 STEP 4-4 이후가
잘렸고, 문서 끝에 표식을 넣어도 나타나지 않았다). 그래서 `<!-- SPLIT -->` 주석으로 나눠
각각 렌더한 뒤 세로로 이어 붙인다. 현재 3파트(01~STEP2 / STEP3~4 / 05~마무리)로 나뉜다.
파트를 늘리려면 `<!-- SPLIT -->` 를 추가하면 된다.

마커 규격은 상위 폴더의 [마커_스타일_가이드.md](../마커_스타일_가이드.md) 를 따른다.
