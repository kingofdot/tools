# 갑지 만들기 · 미리보기 도판

인허가 서대리 「갑지 만들기」 화면 안내 도판. **완성본은 [`자료/화면캡처/미리보기_갑지_최종/`](자료/화면캡처/미리보기_갑지_최종/)** 에 있다(14컷).
구성·규격·갱신 방법은 그 폴더의 README 를 본다.

## 폴더

```
갑지/
  _build_markers2.py                섹션 카드(개요·필요서류·작성안내) 렌더
  결과물/                            생성된 갑지 예시 5장 (원본)
    _모자이크/                        개인정보 가린 사본 · step11 은 이걸 쓴다
  자료/화면캡처/
    test.png  test_컷/               실제 화면 전체 캡처(원본) · 건드리지 않는다
    갑지생성*.png  _popup7.png        화면별 캡처(원본) · 건드리지 않는다
    annotate/
      handoff/                       받은 원본 렌더러 · 수정 금지
      work/                          실사용 렌더러 · 수정은 여기서만
    미리보기_갑지_최종/                 ★ 완성본 14컷
```

## 빌드

```bash
cd "인허가 서대리_미리보기 페이지 작성"
python _build/gen_final.py           # step01~11
python 갑지/_build_markers2.py        # intro1~3
python _build/mask_docs.py           # 결과물 예시 모자이크
```

`_build_markers2.py` 는 렌더 직전에 `design.css` 경로를 절대 경로로 바꾼다.
임시 폴더에서 렌더하기 때문에 상대 경로 그대로는 스타일시트를 못 찾는다.

## 원본 취급

`test_컷/`, `갑지생성*.png`, `결과물/` 은 **원본이라 수정하지 않는다.**
자르거나 가린 결과는 항상 별도 폴더(`미리보기_갑지_최종/img/`, `결과물/_모자이크/`)에 새로 쓴다.
