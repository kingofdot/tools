# 미리보기 파이널 지침

갑지 미리보기 안내 도판(주석 패널)의 **최종 규격**이다.
이 문서 하나만 있으면 코드가 전부 사라져도 같은 결과물을 다시 만들 수 있도록 적었다.

- 대상: `annotate` 계열 · 스크린샷 + 강조 박스 + 번호 + 지시선 + 설명 콜아웃
- 기준 산출물: `갑지/자료/화면캡처/스타일시안/4_주석패널_annotate.png` (**2095 × 2169**, SECTION 01 서류 선택)
- 마커컷2/3 · 섹션 카드 등 다른 계열은 `스타일_가이드.md` 를 따른다.

---

## 0. 세 줄 요약

1. 좌표는 화면 픽셀이 아니라 **섹션 좌표계**에 적는다. 스크린샷을 다시 찍어도 안 깨진다.
2. 주황은 **박스 · 번호 · 지시선 · 설명박스** 네 곳에만. 나머지 UI는 원문 화면의 파랑을 쓴다.
3. 박스는 대상 **바깥 2px**, 지시선은 박스 **오른쪽 바깥 변**에서 시작해 콜아웃 **왼쪽 변 세로 중심**에 닿는다.

## 2. 다시 만들기

```bash
cd "d:/dev/tools/인허가 서대리_미리보기 페이지 작성"
python _build/gen_annotate_sample.py s1          # s0 ~ s5
cp "갑지/자료/화면캡처/annotate/샘플/s1_서류 선택.png" \
   "갑지/자료/화면캡처/스타일시안/4_주석패널_annotate.png"
```

정상 출력:

```
■ SECTION 01 서류 선택 · 섹션 좌표계 810x510 · 항목 9 · 패널 3
  g1 side  grp-s1-1.png   img 3150x801  ×3.889  표시배율 0.741  OK
  g2 side  grp-s1-2.png   img 3150x902  ×3.889  표시배율 0.741  OK
  g3 side  grp-s1-3.png   img 3150x898  ×3.889  표시배율 0.741  OK
→ ...\s1_서류 선택.png  2095x2169
```

`OK` 가 아니면 아래가 뜬다 · 뜨면 렌더 결과를 믿지 말 것.

| 경고 | 뜻 |
|---|---|
| `스테이지 NNNpx > 카드 안쪽 948px` | 콜아웃 오른쪽이 잘린다 (§5 참조) |
| `crop 높이 불일치` | JSON 의 `crop` 과 실제 PNG 크기가 어긋남 |
| `박스 N 이 crop 밖` | 그 박스는 패널 이미지에 안 보인다 |

### 렌더 파이프라인

1. `work/` 의 CSS · JS · 섹션 JSON 을 **한 HTML 파일에 인라인**한다.
   (원본 `example.html` 은 `fetch` 로 JSON 을 읽어서 `file://` 로는 안 돌아간다.)
2. 이미지 경로는 `handoff/img/` 절대 `file:///` 로 치환.
3. Pretendard Variable 을 CDN 에서 링크 → **인터넷 필요**. 끊기면 맑은 고딕으로 떨어지고 줄바꿈이 달라진다.
4. Chrome headless 로 촬영.
   `--force-device-scale-factor=2 --virtual-time-budget=20000 --window-size=1300,4200`
5. `renderGuideSection()` 직후 **`AG_fixWires()`** 를 반드시 호출(§9-3).
6. 흰 배경을 걷어내고 **둘레 36px**(device) 남겨 자른다.

## 3. 좌표계 · 가장 중요한 부분

좌표가 세 단계를 거친다. 이 순서를 헷갈리면 전부 어긋난다.

```
① 원본 업로드 캡처 (한 장)
    └─ x0,y0 만큼 잘라 → ② 섹션 좌표계 (cw × ch)   ← guide-data.json 의 b·crop 은 전부 여기
                              └─ crop 으로 잘라 저장 → ③ 패널 PNG (원본 배율 그대로, 예: ×3.889)
                                                        └─ 화면에서 IW 로 축소 표시 (표시배율 k)
```

- `b = [x, y, w, h]` · 대상 요소의 실제 경계. **섹션 좌표계**.
- `crop = [x, y, w, h]` · 패널이 보여줄 영역. **섹션 좌표계**. 좌우는 자르지 않는다(`x=0, w=cw`).
- `k = IW / crop[2]` · 화면 표시 배율. side 는 `600 / cw`.

### 실제 숫자로 따라가기 (s1 · g1 · 1번 박스)

```
b    = [24, 88, 508, 69]        crop = [0, 74, 810, 206]        cw = 810
k    = 600 / 810 = 0.740741

x = round((24 - 0) × k) + IB = round(17.78) + 1 = 19
y = round((88 - 74) × k) + IB = round(10.37) + 1 = 11
w = round(508 × k) = 376        h = round(69 × k) = 51

박스 렌더  left 19-2=17  top 11-2=9  width 376+4=380  height 51+4=55
박스 오른쪽 바깥 끝 = 17 + 380 = 397          (스테이지 좌표)
연결선 시작 sx = 0 + 19 + 376 + 2 = 397       ← 정확히 일치해야 한다
```

`IB = 1` 은 `.ag-img img` 의 1px 테두리 보정이다. 이게 없으면 박스 전체가 스크린샷보다 1px 왼쪽·위로 밀린다.

### 패널 PNG 무결성

`crop[3] × (PNG폭 / crop[2])` 가 PNG 높이와 ±1px 안에 들어와야 한다.
15장 전부 통과 확인했다(원본 배율 ×3.889 로 일관).

## 4. 레이아웃 상수

```js
// work/annotation-guide.js
side : { IW: 600, GAP: 22, CW: 326, IX: 0, CPL: 34 }   // 항목이 위→아래로 나열될 때
below: { IW: 940, CW: 226, LANE: 24, CPL: 22 }         // 항목이 좌→우로 나열될 때
const BP = 2;   // 박스를 대상 바깥으로 띄우는 여백. 사면 동일
const IB = 1;   // 이미지 1px 테두리 보정
const NUM = { place: 'corner', gap: 6, w: 22 };
```

파생값 (side):

| 이름 | 식 | 값 |
|---|---|---|
| `MID` | `IX + IW + 11` | 611 |
| `CX` (콜아웃 왼쪽 변) | `IX + IW + GAP` | 622 |
| 스테이지 폭 | `CX + CW` | **948** |
| 카드 안쪽 폭 | `1010 - 2(테두리) - 60(패딩)` | **948** |

**스테이지 폭 ≤ 948 은 절대 조건이다.** `.ag{overflow:hidden}` 이라 넘으면 조용히 잘린다.
원본은 `IX:18` 이라 966 → 오른쪽 18px 이 잘리고 있었다.

## 5. 색 규칙 ★

> **주황은 박스 · 번호 · 지시선 · 설명박스에만.** 나머지는 원문 화면의 파랑을 쓴다.
> 이렇게 하면 "주황이 보이면 그건 전부 안내 표시" 라는 규칙이 성립한다.

파랑 값은 눈대중이 아니라 원문 스크린샷 픽셀에서 뽑았다 ·
`사업장 정보 입력` 버튼 = `rgb(43, 98, 239)`.

```css
/* work/annotation-guide.css · .ag 안의 토큰 */
--ag-ink:#0f172a;  --ag-sub:#5b6779;  --ag-line:#e2e8f0;

/* 주황 · 안내 표시 전용 */
--ag-accent:#ea580c;                 /* 번호 원 배경 */
--ag-accent-ink:#9a3412;             /* 콜아웃 제목 */
--ag-accent-line:#fcd9bd;            /* 콜아웃 테두리 */
--ag-box-line:rgba(234,88,12,.45);   /* 박스 테두리 */
--ag-fill-a:rgba(234,88,12,.055);    /* 박스 필 · 왼쪽 */
--ag-fill-b:rgba(234,88,12,.005);    /* 박스 필 · 오른쪽(거의 투명) */
--ag-glow:rgba(234,88,12,.20);       /* 박스 바깥 번짐 */
--ag-wire:rgba(234,88,12,.50);       /* 지시선 점선 */

/* 파랑 · 나머지 전부 */
--ag-blue:#2B62EF;                   /* SECTION 01 */
--ag-blue-ink:#1E4FD0;               /* 패널 라벨 글자, 01-1 칩 글자 */
--ag-blue-chip:#EAF0FE;              /* 01-1 칩 배경 */
```

| 요소 | 색 |
|---|---|
| `SECTION 01` | `--ag-blue` |
| `01-1` 칩 | 배경 `--ag-blue-chip` / 글자 `--ag-blue-ink` |
| 패널 라벨(`안내 · 검색 · 필터`) | `--ag-blue-ink` |
| 카드 제목 / 부제 | `--ag-ink` / `--ag-sub` |
| 강조 박스 | 테두리 `--ag-box-line`, 필 `--ag-fill-a→b`, 번짐 `--ag-glow` |
| 번호 원 | `--ag-accent` 100% (유일하게 불투명 · 흰 숫자 가독성) |
| 지시선 | `--ag-wire` |
| 콜아웃 | 테두리 `--ag-accent-line`, 제목 `--ag-accent-ink`, 본문 `--ag-sub` |

`--ag-accent-chip:#fff3ea` 는 이제 쓰이지 않는다(파랑 칩으로 교체됨).

## 6. 강조 박스

```css
.ag-box{
  position:absolute;
  box-sizing:border-box;                 /* ← 빠지면 안 됨. §6-1 */
  border:1px solid var(--ag-box-line);
  border-radius:6px;
  background:linear-gradient(95deg,var(--ag-fill-a),var(--ag-fill-b));
  box-shadow:0 0 9px 1px var(--ag-glow); /* 단단한 링이 아니라 blur 로 사라짐 */
}
```
```js
left: r.x - BP,  top: r.y - BP,  width: r.w + BP*2,  height: r.h + BP*2
```

### 6-1. `box-sizing:border-box` 가 왜 필수인가

원본에는 이게 없었다. 그러면 `width` 가 **내용 폭**이 되고 테두리가 밖으로 더해져
박스 오른쪽·아래만 4px 씩 커진다 · **좌·상은 딱 맞고 우·하만 큰 비대칭**이 된다.
그 상태에서 지시선을 `left + width` 에 붙이면 선이 박스 안으로 4px 파고든다.
실측으로 확인했던 값: 테두리 926~929, 선 시작 922.

### 6-2. 바깥 경계를 투명하게

`box-shadow` 의 세 번째 값(blur)을 쓴다. `0 0 0 2px` 는 blur 0 이라 딱 잘린 링이 되고,
`0 0 9px 1px` 은 테두리에서 1px 벌어진 뒤 9px 에 걸쳐 서서히 사라진다.

### 6-3. 필을 더 줄이거나 없애기

`--ag-fill-a` / `-b` 만 만진다. `transparent` 로 두면 테두리 + 번짐만 남는다.
`.055` 아래로는 사실상 안 보이므로 그럴 바엔 빼는 게 낫다.

## 7. 번호 원

```css
.ag-num{
  position:absolute; transform:translate(-50%,-50%);
  width:16px; height:16px; padding:0; border-radius:50%;   /* ← 정원. §7-1 */
  background:var(--ag-accent); color:#fff;
  font-size:9.5px; font-weight:800; line-height:1;
  display:flex; align-items:center; justify-content:center;
  box-shadow:0 0 0 1.5px #fff;                             /* 흰 링으로 배경과 분리 */
}
```

`transform:translate(-50%,-50%)` 때문에 **좌표는 항상 '중심'** 이다.

| `AG_NUM.place` | 중심 좌표 | 성격 |
|---|---|---|
| `'corner'` (기본) | `(IX + r.x - BP, r.y - BP)` = 박스 왼쪽 위 모서리 | 번호와 박스가 한 덩어리로 읽힘. 모서리를 조금 덮음 |
| `'outside'` | `(박스왼쪽 - 6 - 11, 박스위 + 11)` | 화면을 전혀 안 가림. 결속은 약간 약함 |

전환은 렌더 전에 `AG_NUM.place = 'outside';` 한 줄.
`gen_annotate_sample.py` 에 `outside` 변형이 등록돼 있다 · `python ... s1 outside`.

### 7-1. 알약이 아니라 정원인 이유

원본은 `min-width:22px; padding:0 6px; border-radius:11px` 이라 실제로는 **34×22 알약**이었다.
`border-radius:50%` 만 줘도 패딩 때문에 계속 타원이 된다.
`width` 를 고정하고 `padding:0` 으로 해야 진짜 원이 되고, 가로 폭이 34 → 16 으로 절반 이하가 된다.

## 8. 설명 콜아웃

```css
.ag-co{position:absolute;background:#fff;border:1px solid var(--ag-accent-line);
  border-radius:9px;padding:9px 12px;box-shadow:0 2px 6px rgba(124,45,18,.07)}
.ag-co h3{margin:0 0 3px;font-size:12.5px;font-weight:700;letter-spacing:-.01em;color:var(--ag-accent-ink)}
.ag-co p {margin:0;font-size:12px;line-height:1.55;color:var(--ag-sub);text-wrap:pretty}
```

- 가로: `left = CX(622)`, `width = CW(326)` → 오른쪽 끝 948 = 카드 안쪽과 정확히 일치.
- 세로: 박스 세로 중심에 맞추고, 겹치면 아래로 밀어낸다(`cy` 누적, 간격 10px).
- 제목은 `N. 제목` 형식.

**세로 위치는 추정값이다.** `estH = 34 + ceil(글자수 / 34) × 19` 로 높이를 어림잡는데,
한글은 이 추정이 자주 틀린다(5번 항목은 2줄로 잡지만 실제 1줄). 그래서 콜아웃 사이 간격이 들쭉날쭉하다.
지시선 끝점만은 실측으로 보정한다(§9-3). 간격 자체의 균일화는 아직 미해결(§13).

## 9. 지시선

### 9-1. 규격

```css
.ag-wire{position:absolute;left:0;top:0;overflow:visible;pointer-events:none}
.ag-wire path{fill:none;stroke:var(--ag-wire);stroke-width:1;
  stroke-dasharray:3 4;stroke-linecap:round}
```

- **화살촉 없음.** 원본의 `.ag-tip-l` / `.ag-tip-u` 는 쓰지 않는다.
- 점선 3px 찍고 4px 띄움, 끝 둥글게.
- div 3개(가로·세로·가로)로 그리던 방식은 곡선이 불가능해서 **스테이지 위 SVG 오버레이**로 바꿨다.

### 9-2. 곡선식

시작점은 **박스 오른쪽 바깥 변의 세로 중심**, 끝점은 **콜아웃 왼쪽 변의 세로 중심**.
양 끝이 수평으로 붙는 3차 베지어 한 획이다.

```js
// side
const c  = round(r.y + r.h/2);
const sx = min(IX + r.x + r.w + BP, MID - 12);
const k  = max(30, (CX - sx) * 0.45);
d = `M${sx} ${c} C ${sx+k} ${c}, ${CX-k} ${ey}, ${CX} ${ey}`

// below (세로 S자)
const bx = round(r.x + r.w/2), by = r.y + r.h + BP, cx = r.cx + CW/2, ct = r.ct;
const k  = max(24, (ct - by) * 0.5);
d = `M${bx} ${by} C ${bx} ${by+k}, ${cx} ${ct-k}, ${cx} ${ct}`
```

곡률 계수 `0.45` 를 낮추면 박스에서 더 빨리 빠져나가 화면을 덜 지난다. 높이면 더 완만해진다.

### 9-3. 끝점 실측 보정 · `AG_fixWires()`

`estH` 가 틀리므로 **DOM 에 올라간 뒤 콜아웃의 실제 높이를 재서 다시 그린다.**
path 에 시작점·끝점 x 를 `data-` 로 실어두고 끝점 y 만 교체한다.

```js
const ey = Math.round(co.offsetTop + co.offsetHeight / 2);
path.setAttribute('d', `M${sx} ${c} C ${sx+k} ${c}, ${ex-k} ${ey}, ${ex} ${ey}`);
```

**호출을 빠뜨리면 지시선이 콜아웃 중심에서 최대 20px 어긋난다.**

```html
<script>
  root.innerHTML = renderGuideSection(sec);
  AG_fixWires();            // ← 반드시
</script>
```

`data-sx` 가 있는 path(= side 모드)만 보정한다. below 모드는 원래 콜아웃 윗변 중앙에 닿으므로 대상이 아니다.

## 10. 카드 셸

## 12. 새 화면을 추가할 때

**눈대중 금지.** 박스가 어긋나면 이 시안은 전부 무너진다.

1. 폼 화면을 한 장으로 캡처하고 섹션별로 좌우 폭을 통일해 자른다.
2. 입력창 경계를 **픽셀 스캔**으로 검출한다. 카드 배경(흰색)보다 어두운(평균 밝기 < 249) 픽셀이
   이어지는 행/열이 입력창 테두리다. 세로 스캔으로 상·하단 y, 가로 스캔으로 좌·우 x 를 얻는다.
   (카드 안쪽 여백은 보통 x=24, 우측 778 형태로 반복 검출된다.)
3. 얻은 값을 **섹션 좌표계**로 환산해 `b = [left, top, width, height]` 로 적는다.
4. 항목을 2~3개씩 묶어 `g` 를 정의한다. `crop` 은 `min(top) - 14` ~ `max(bottom) + 14`.
5. 그 crop 으로 패널 PNG 를 잘라 `handoff/img/` 에 저장한다.
6. `python _build/gen_annotate_sample.py <key>` → **검증 줄이 전부 `OK`** 인지 먼저 본다.
7. 그다음 눈으로 확인한다.

## 15. 아직 안 고친 것

의도적으로 남겨둔 항목이다. 손대려면 이 순서를 권한다.

1. **콜아웃 세로 간격 불균일** · `estH` 추정 오차 때문. `AG_fixWires()` 와 같은 방식으로
   실측 후 재배치하면 해결된다. 지금은 5번 콜아웃 아래가 유독 넓다.
2. **패널 위아래 반토막 행** · `crop = min(top)-14 ~ max(bottom)+14` 규칙이 시각적 행 경계를 모른다.
   01-1 아래 `검색 결과 총 서류 5종` 행, 01-2 위 분야 칩 행이 절반만 보인다.
   `갑지/_cut_page.py` 의 배경행 검출을 쓰면 자동으로 맞출 수 있다.
3. **01-1 · 01-3 중복** · 두 패널의 crop 이 둘 다 `y=74` 에서 시작해 좌측 폼이 통째로 두 번 나온다.
   `crop` 좌우를 자르지 않는 규칙 때문에 주석 없는 우측 요약 컬럼도 매 패널에 딸려 온다.
4. **7번 번호가 헤더를 조금 덮음** · 박스가 화면 상단에 붙어 있어 모서리로 빼도 피할 자리가 없다.
   `AG_NUM.place='outside'` 로 바꾸면 사라진다.
5. **below 모드 미검증** · s0 · s5 에만 쓰이고 아직 눈으로 확인하지 않았다.

## 16. 절대 어기지 말 것

1. `handoff/` 는 받은 원본이다. **수정하지 않는다.** 모든 변경은 `work/` 에서.
2. 스테이지 폭은 **948 이하**. 넘으면 조용히 잘린다.
3. `.ag-box` 의 `box-sizing:border-box` 를 빼지 않는다.
4. 렌더 후 **`AG_fixWires()` 호출**을 빠뜨리지 않는다.
5. 주황은 **박스 · 번호 · 지시선 · 설명박스** 네 곳에만.
6. 좌표는 항상 **섹션 좌표계**로 적는다. 화면 픽셀을 직접 적지 않는다.
7. 원본 스크린샷 PNG 는 수정하지 않는다. 자를 일이 있으면 새 파일로 저장한다.
