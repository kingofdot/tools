값을 바꿀 때는 반드시 아래 "단일 소스"를 고치고, 여기 표를 같이 갱신한다.

## 색

브랜드 블루 + 보색 오렌지 두 축이다. 오렌지는 **마커 전용**이고 카드 본문에는 쓰지 않는다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 브랜드 블루 | `#1E51D5` | 번호 배지, 제목 강조, 버튼 |
| 짙은 블루 | `#143AA0` | 큰 제목 |
| 연한 블루 워시 | `#EEF5FF` | 아이콘 박스, 연한 섹션 배경 |
| 헤더 밴드 | `#E9F1FF` | 카드 제목 줄 바탕 |
| 떠오른 블록 | `#F5F8FE` | 흰 본문 위 옅은 블록 |
| 본문 글자 | `#121826` / `#3B4557` | 제목 / 본문 |
| 보조 글자 | `#6A7488` | 캡션 |
| 헤어라인 | `#E4EAF4` | 카드 내부 구분선 |
| 카드 외곽 | `#C9D6EC` | 카드 테두리 |
| 시트 바탕 | `#F7F9FC` | 마커컷 배경 |
| **마커 오렌지** | `#F5820A` | 강조박스·리더선·라벨 (마커 전용) |

### 스크린샷 테두리는 `#E1E8F4` 하나로

마커컷 안의 스크린샷·팝업 테두리는 **`1px solid #E1E8F4` + `border-radius:12px` + `background:#fff`** 로 통일한다.
`_popup7.png` 처럼 원본에 테두리가 구워진 이미지는 **CSS 로 잘라내고** 이 규격을 다시 입힌다
(구워진 테두리는 변마다 두께가 달라 다른 컷과 어긋난다).

> `design.css` 의 `--line:#E4EAF4` 와 3 단위 차이가 있다. 카드 내부 구분선과 스크린샷 테두리는
> 쓰임이 달라 굳이 합치지 않았다. 합칠 거면 두 곳을 같이 고칠 것.

## 마커컷 규격

`_build_markers2.py` 가 빌드 때 각 flow 의 스타일을 덮어쓰므로, flow 파일에 무엇이 적혀 있든 결과는 아래로 통일된다.

| 항목 | 값 |
|---|---|
| 강조박스 여백 | **대상 바깥 2px 균일** (`PAD`) |
| 강조박스 | `2.2px solid #F5820A` · `radius 9px` · 오렌지 글로우 |
| 라벨 글씨 | **16px / 700** (`FONT_PX`) — 컷별 예외는 `FONT_OVERRIDE` |
| 라벨 박스 | `padding 4px 9px` · `radius 10px` · `1.6px` 테두리 · 흰 배경 |
| 리더선 | `2.2px` 둥근 끝. 앵커 점 r4.5 + 헤일로 r8(투명도 .20) |
| 출력 배율 | 2배(레티나). 좌표는 모두 1배 CSS px 기준 |
| 폭 통일 | `NORMALIZE` — 지금은 **끔**(컷마다 꽉 자름). 켜면 가장 넓은 컷에 맞춰 좌우 여백만 채운다 |

### 섹션 카드는 X 사이즈가 같아야 한다 ★

개요·필요서류처럼 **나란히 놓고 보는 섹션 카드는 가로 폭이 반드시 같아야 한다.**
폭이 몇 px 만 어긋나도 문서에 넣었을 때 카드가 들쭉날쭉해 보인다.

잘라내기는 내용 기준이라 그냥 두면 컷마다 달라진다. 그래서 `_build_markers2.py` 의
`WIDTH_GROUPS` 에 묶어 두면 빌드가 **묶음 안에서 가장 넓은 컷에 맞춰 좌우 여백만 채운다**
(리사이즈 없음 → 글씨 크기는 그대로).

```python
WIDTH_GROUPS = {
    '섹션카드': ['갑지_01개요_marker', '갑지_02필요서류_marker'],
}
```

현재 두 컷 모두 **2253px**. 섹션 카드를 새로 만들면 반드시 이 묶음에 이름을 추가할 것.
빌드 로그에 `[섹션카드] 폭 2253 로 통일` 이 찍히는지로 확인한다.

### 지켜야 할 규칙 넷

1. **강조박스는 대상을 반드시 포함한다.** 대상이 박스 밖으로 튀어나오면 안 된다.
   빌드가 대상의 실제 테두리를 찾아 2px 띄우되, 지정 영역은 무조건 감싼다.
2. **번호 핀은 쓰지 않는다.** 점 → 선 → 박스 흐름만 쓴다([마커_스타일_가이드.md](마커_스타일_가이드.md)).
3. **좌표를 일괄 이동할 때 `<marker>` 정의는 건드리지 않는다.**
   화살촉 path 까지 같이 옮기면 화살촉이 사라진다(2번 컷에서 실제로 겪었다).
4. **원본 PNG 는 고치지 않는다.** 자르기·테두리 교체는 전부 CSS 로 한다.

## 다시 만들기

```
python _build/render.py --h=4000 card_04_overview   # 카드 → 컷/*.png
python 갑지/_build_markers2.py                      # 마커컷 전량
python 갑지/_build_markers2.py 8                    # 8번만
python 갑지/_build_guide.py                         # 갑지 이용가이드 PNG
```

카드는 재현성이 확인돼 있다 — 같은 입력으로 다시 렌더하면 **바이트 단위로 동일한 PNG** 가 나온다.
