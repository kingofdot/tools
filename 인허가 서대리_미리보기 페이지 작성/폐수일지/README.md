# 폐수일지 · 미리보기 도판

인허가 서대리 「폐수 일지」 화면 안내 도판. 완성본은 [`미리보기_폐수일지_최종/`](미리보기_폐수일지_최종/).
카드 규격은 갑지와 동일(폭 2955 · 테두리 1px `#C9D6EC` · 그림자 없음).

## 갑지와 다른 점 · tb 레이아웃

폐수일지는 입력행이 카드 **전폭**을 쓴다. 우측 콜아웃(side)을 쓰면 화면이 좁아져 글씨가
뭉개지므로, 콜아웃을 **위·아래 밴드**에 놓거나 화면의 **빈 자리에 자유 배치**하는
`tb` 모드를 쓴다(`annotate/work/annotation-guide.js` 에 추가).

| 항목 옵션 | 뜻 |
|---|---|
| `band='top'/'bottom'` | 콜아웃을 위/아래 밴드 어디에 둘지. 생략하면 대상 위치로 자동 |
| `cox=px` | 밴드 안 콜아웃 x 직접 지정 (지시선 교차 회피) |
| `cpos=[x,y]` | 화면 빈 공간(달력 오른쪽 등)에 자유 배치. band 무시 |

## 폴더

```
폐수일지/
  sections.py                 ★ 섹션 정의 데이터 · 수정은 여기서만
  _build_pesu.py              빌더 (스냅 → crop → tb 렌더)
  원본/                        전체 화면 캡처 3배 · 수정 금지
    폐수일지-입력전.png          빈 폼 (높이 16384 한계 · 하단 일부 잘림)
    폐수일지-입력후1.png         값 채움 전반부 (~원료·첨가제 시작에서 잘림)
    폐수일지-입력후2.png         값 채움 후반부 (폭기조~특기사항)
  목록등자료/폐수일지/            드롭다운 펼친 보조컷 · scale=1
  미리보기_폐수일지_최종/          ★ 완성본 (step01.png ~)
    img/                      패널로 잘라낸 스크린샷
    guide-data.json           스냅까지 끝난 최종 좌표
```

## 빌드

```bash
cd "인허가 서대리_미리보기 페이지 작성"
python 폐수일지/_build_pesu.py         # 전량
python 폐수일지/_build_pesu.py 01      # 해당 스텝만
```

## 좌표계

- `원본/` 캡처는 **3배**: CSS 좌표 = 원본 픽셀 / 3. 본문 카드 영역 CSS x 438~1464.
- `목록등자료/` 보조컷은 **1배**(scale=1 지정).
- 섹션 카드 세로 경계는 `sections.py` 머리말에 기록.

## 진행 상황

| 스텝 | 내용 | 상태 |
|---|---|---|
| step01 | 작성 기간과 지역 | 완료 |
| step02~ | 기본 설정 · 시설 가동 시간대 · 용수 및 폐수량 · 전력 · 슬러지 · 원료 및 첨가제 · 약품 · 폭기조 · 수질오염물질 측정 · 자동측정기기 점검 · 특기사항 | 예정 |

## 주의

- 원본 PNG 는 수정하지 않는다. 잘라낸 결과만 `미리보기_폐수일지_최종/img/` 에 새로 쓴다.
- **원료·첨가제~약품의 입력값 컷**은 입력후1(잘림)과 입력후2(폭기조부터) 사이에 빠졌을
  수 있다. 해당 스텝 작업 때 입력전 컷으로 대체하거나 재캡처를 요청할 것.
- 입력후 캡처 우상단에 계정명이 보이면 크롭에서 제외하거나 모자이크한다
  (지금까지 크롭 범위에는 안 들어옴).
