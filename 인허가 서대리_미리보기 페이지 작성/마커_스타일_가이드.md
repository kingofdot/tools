# 인허가 서대리 · 지시선-박스 마커 스타일 가이드

스크린샷 위에서 특정 지점을 가리키는 **공통 안내 마커** 규격입니다.
사이트 전체(미리보기·가이드·블로그 캡처)에서 동일하게 씁니다.

---

## 1. 구성 (3요소)

| 요소 | 설명 |
|---|---|
| ① 앵커 점 | 가리킬 지점에 찍는 작은 점 + 은은한 헤일로 |
| ② 루트(√) 리더선 | 점에서 대각으로 올라간 뒤 짧게 수평으로 빠지는 선 |
| ③ 라벨 박스 | 리더선 끝에 붙는 문구 박스 |

> 큰 번호 핀은 쓰지 않습니다(답답함). 점 → 선 → 박스 흐름만 사용.

---

## 2. 색 · 토큰

| 항목 | 값 |
|---|---|
| 액센트(점·선·테두리·글씨) | **오렌지 `#F5820A`** (파랑 메인 `#1E51D5`의 보색) |
| 라벨 배경 | 흰색 불투명 `#FFFFFF` |
| 글로우(바깥 주황빛) | `0 0 6px rgba(245,130,10,.35), 0 0 15px 1px rgba(245,130,10,.16)` |
| 글꼴 | 맑은 고딕(Malgun Gothic) `18px` / 굵기 `700` |

---

## 3. 치수 (원본 스크린샷 픽셀 기준, 출력은 2x 레티나)

| 항목 | 값 |
|---|---|
| 앵커 점 반지름 | `4.5` |
| 헤일로 반지름 / 투명도 | `8` / `0.20` |
| 리더선 대각 | 가로 `35`, 세로 `36` |
| 리더선 수평 | `54` |
| 리더선 굵기 | `2.2` (둥근 끝) |
| 박스 패딩 | `9px 15px` |
| 박스 라운드 | `11` |
| 박스 테두리 | `1.6` |

---

## 4. 배치 규칙

- 앵커 점은 **가리킬 대상의 중심**에 찍는다.
- 라벨 박스는 대상·다른 라벨·카드 테두리와 **겹치지 않게** 둔다.
- 리더선 방향 4종 (`side`):

  | 값 | 방향 | 쓸 때 |
  |---|---|---|
  | `ur` | 오른쪽 위 (기본) | 대상이 화면 왼쪽/가운데 |
  | `ul` | 왼쪽 위 | 대상이 화면 오른쪽 |
  | `dr` | 오른쪽 아래 | 위쪽이 막혔을 때 |
  | `dl` | 왼쪽 아래 | 대상이 오른쪽 + 위 막힘 |

---

## 5. 적용 방법

1. 대상 스크린샷을 `컷/` 폴더에 넣는다.
2. 스펙 JSON을 만든다.

   ```json
   {
     "base": "../컷/image.png",
     "out":  "../컷/image_marker.png",
     "markers": [
       { "x": 317, "y": 224, "text": "필요한 갑지 서류를 선택하세요", "side": "ur" }
     ]
   }
   ```

   - `x,y` = **원본 스크린샷 픽셀** 좌표(가리킬 지점).
   - `markers`에 여러 개 넣으면 한 이미지에 여러 마커.

3. 실행:

   ```bash
   python "_build/annotate.py" spec.json
   ```

   또는 코드에서:

   ```python
   from annotate import annotate
   annotate(base="../컷/image.png", out="../컷/out.png",
            markers=[{"x":317,"y":224,"text":"...","side":"ur"}])
   ```

> **스타일을 바꿀 땐** `_build/annotate.py` 상단의 `TOK` 딕셔너리 **한 곳만** 고치면
> 이후 만드는 모든 마커에 동일하게 반영됩니다(색·치수·글꼴 단일 소스).
