# 질의회신 관련법령 자동보충 엔진 (v2)

질의·회신 답변에 나오는 법령을 **국가법령정보 API로 실제 조문·별표 원문을 fetch**하여 관련법령 표를 만드는 생성기.

## 무엇이 달라졌나 (v1 → v2)
- v1: 관련법령 표가 폐기물 별표 4의3/4의2/5의3 + 제13조의2 **고정**이라, 답변이 인용한 실제 조항(제29조·제31조·별표5·별표7 등)이 표에 안 나왔다.
- v2: **답변·질의에서 인용한 모든 법령을 파싱 → 실제 원문 fetch**. 조/항/호/목 단위까지, 별표는 인용 호·목으로 점프. 3계층으로 정리:
  - **본문 인용**: 질의·답변에 나온 조항 (조/항/호/목 원문, 회신 당시·현행 다르면 병기)
  - **연계 법령**: 그 조항이 다시 인용하는 조항 (예: 시행규칙 조문이 "법 제25조"를 인용하면 그 조문도)
  - **보충**: 인허가 서대리가 이해를 돕기 위해 덧붙인 조항 (폐기물 정의·재활용 원칙·재활용 가능 유형 등)

## 파일
| 파일 | 역할 |
|---|---|
| `lawengine.py` | 법령 fetch 엔진. 조/항/호/목 세밀 추출, 회신 당시(as-of) 버전, 별표 PDF 추출(페이지네이션). 캐시 자동생성. |
| `lawrefs.py` | 인용 파서(법령명 상속 `같은 법/영/규칙`) + 연계 + `build_table()` 3계층 표 생성. |
| `build_qa_v2.py` | 폐기물재활용 173건 → `posts_질의회신_all.json` (default_law=폐기물관리법 시행규칙). |
| `build_all_v2.py` | 나머지 5개 소스 → posts (소스별 default_law·회신연도 REFDATE). |
| `qa_parsed.json` | 폐기물재활용 파싱본. `lawcache_qa.json` | 폐기물 별표 4의2/4의3/5의3 캐시. |

## 실행
```
cd _lawgen
python build_qa_v2.py            # 폐기물재활용 173
python build_all_v2.py           # 사업장·지정·환평·2017·2010
ONLY=_지정폐기물 python build_all_v2.py   # 한 소스만
```
출력은 `인허가 서대리 블로그/posts_*.json` (전부 비공개). 첫 실행은 법령 fetch로 느리고, 이후 `generic_lawcache.json`·`byl_textcache.json`(gitignore) 캐시로 빨라진다.
