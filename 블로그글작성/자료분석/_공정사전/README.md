# 표준 공정 사전

통합환경허가 검토결과서 **42개 사업장**의 `2.2 통합허가 대분류 공정 설명`에서 뽑은
**418개 공정**을 **표준 공정 30종**으로 묶고, 공정별 설명을 템플릿 문장으로 정리한 것.

> 목적 — 화면에서 "분쇄 공정"을 고르면 그 공정의 설명을 바로 끌어다 쓸 수 있게 하는 **연계 데이터**.
> 사업장마다 달라지는 목적물·시설·수치는 `{슬롯}`으로 비워 두었다.

## 파일


`슬롯`은 이름만 담고 값은 최상위 `슬롯사전`에 한 번만 둔다. 슬롯 값을 늘릴 때 한 곳만 고치면 된다.

## 쓰는 법

```python
import json, re
D = json.load(open('공정사전.json', encoding='utf-8'))
SLOT = D['슬롯사전']

def find(q):
    """공정유형·별칭·관련시설 어디서든 걸리면 반환."""
    return [p for p in D['공정']
            if q in p['공정유형'] or any(q in a for a in p['별칭'] + p['관련시설'])]

def render(p, **kw):
    """{슬롯}을 채워 설명을 완성. 안 채운 슬롯은 {그대로} 남는다."""
    return [re.sub(r'\{(\w+)\}', lambda m: kw.get(m.group(1), m.group(0)), s)
            for s in p['설명']]

p = find('분쇄')[0]
print(render(p, 대상물='건설폐기물', 입도='50mm 이하',
             시설='선별시설', 오염물질='비산먼지', 방지시설='여과집진시설(B/F)')[0])
# → 건설폐기물을 파쇄·분쇄시설에 투입하여 50mm 이하로 파쇄하는 공정이다.
```

`helper.py` 에 위 함수가 들어 있다. `python helper.py 분쇄` 로 바로 확인할 수 있다.

## 만든 방법과 한계

1. 검토결과서 PDF에서 뽑은 `공정_설명` 원문은 표의 셀이 줄바꿈되며 **열 순서가 뒤엉켜** 있다.
   공정번호(`P-01` / `PU-02` / `PW-03`)를 앵커로 잡고 위·아래 줄의 짧은 이름 조각을 끌어와 행을 복원했다.
   418개 전건에서 공정명을 복원했고, 병합 셀로 이름을 공유하는 12건은 이웃에서 상속(`_이름추정: true`)했다.
2. 복원한 공정명을 정규식 규칙으로 표준 30종에 분류했다. `공정_사업장별.json`의 `유형`·`표준공정id` 필드.
3. **설명 문장은 원문을 그대로 쓰지 않고 다시 썼다.** 원문은 표에서 끊긴 조각이라 문장이 성립하지 않는 것이 많다.
   대신 각 표준공정에 `원문예시`로 실제 표현을 3개까지 붙여 두었으니 대조해 볼 수 있다.
4. 시설 명칭과 근거는 **폐기물관리법 시행령 [별표 3] 폐기물 처리시설의 종류**를 따랐다.
5. `퇴비화공정`은 표준 항목으로 두었으나 42개 사업장 코퍼스에는 해당 공정이 없다(`수록공정수: 0`).
   `선별`·`탈수`·`용융`·`증발농축`·`정제/증류`·`악취 저감`은 1건뿐이라 원문 근거가 얇다.
