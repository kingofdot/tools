① 기간 · 지역

일평균 온도를 KMA에서 받아 각 일자에 넣습니다. 로컬 프록시(kma_proxy.py)가 실행 중이어야 합니다. — 터미널에서 python kma_proxy.py

📅 작성 대상일 선택 — 시작일·종료일로 기간을 잡고, 아래 달력에서 제외할 날짜(공휴일·휴무일)를 클릭하면 빨간 취소선으로 빠집니다. 다시 누르면 복구됩니다.
