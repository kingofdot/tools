■ 주요 작업 목록

1. Word 내보내기 기능 구현
   - 조문/별표 선택 패널 UI 추가 (좌우 2열, 기본 미선택)
   - docx@8.5.0 라이브러리 head에 직접 로드 (index.umd.js)
   - 2컬럼 표 생성: 기준(50%) | 준수계획(50%) 빈칸
   - 섹션마다 별도 페이지 (조 단위 / 별표 단위)

2. 헤더 구성
   - line1 (좌측정렬, 9pt): {법령명} {제N조} 또는 {법령명} [별표 N의 M]
   - line2 (가운데정렬): 조문제목 또는 별표제목
   - 시행일자: <YYYY. M. D.> 파란색(#1d4ed8)으로 line1 끝에 표시

3. 별표번호/가지번호 처리
   - 앞 영선 제거: "0005" → "5", "04" → "4"  (Number() 변환)
   - 가지번호 0이면 "별표 N"만, 0 초과이면 "별표 N의 M"

4. 별표 내용 파싱
   - 별표내용[0] (type=title, ■) → 헤더 텍스트로 사용
   - [시행일] 포함 줄 제거
   - "~: NNNN년 N월 N일" 패턴 날짜 줄 제거

5. 조문 파싱 (항/호/목 계층)
   - 조 단위로 하나의 섹션
   - 항 → 호 → 목 재귀 평탄화, depth에 따라 들여쓰기 (150 단위)
   - ① ② ... → 제1항 제2항 ... 변환 (⑳까지 대응)

6. 표 테두리 확정
   - 바깥 4선: THICK (두껍게)
   - 내부 가로선: NIL (없음) — 단, 헤더 하단 / 서브헤더 하단만 SINGLE
   - 내부 세로선: INNER (기준|준수계획 사이)
   - 표마다 가로줄 4개: 최상단 / 별표제목아래 / 기준준수계획아래 / 최하단
   - 셀 레벨에서 top:NIL + bottom:NIL 직접 명시 (라이브러리 insideH 버그 우회)
   - 마지막 행은 bottom 미지정 → 테이블 bottom:OUTER 상속

7. 자동 XML→JSON 파싱
   - 법령 클릭 시 자동으로 XML 파싱 실행 (silent 모드)
   - XML→JSON 수동 버튼 제거

8. 검색 동작 변경
   - 검색 후 첫 번째 법령 자동 선택 제거
   - 사용자가 직접 클릭해야 본문 로드
