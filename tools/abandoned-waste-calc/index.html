산정 기준

보증액 = 허용보관량(t) × 처리단가(원/t) × 계수
총 이행보증금액 = 모든 행 보증액 합계
계수 — 일반 폐기물처리업자·신고자 2배 · 건설폐기물 수집·운반/중간처리업자 1.5배 (사업자 구분 선택 시 자동, 수정 가능)
처리단가 — 폐기물 종류를 드롭다운에서 선택하면 고시 기준단가가 자동 입력됩니다. 별표에 없는 폐기물은 「기타 (직접 입력)」을 선택해 종류·단가를 직접 입력하세요.
