# 검토자료 — 사람이 작업·검토하는 영역

쓸자료 의 정확도를 유지하기 위한 작업·검증·이력. 시스템 코드는 이 폴더 안 내용을 직접 import 하지 않음.

## 구성

### 검토사항/
`law_active/` 로 승격되기 전 WIP 조문·별표. `answer`/`condition`/`위임` 같은 가공 필드를 사람이 채워가는 중. 같은 스키마이지만 미완성 상태가 있을 수 있음.

```
검토사항/
├── 법/                  (제13조, 제13조의2)
├── 시행령/              (제7조)
└── 시행규칙/
    ├── 별표5, 5의3, 5의4, 6, 7, 8, 9, 17, 17의2 (9개)
    └── _원본백업/       (수정 전 스냅샷)
```

`_API검토_검토사항.md` 에 API 와의 차이가 정리됨. 사용자가 항목별 `[수정]/[확인]/[무시]` 결정하면 반영.

### 도구/
재실행 가능한 자동화 스크립트.

| 스크립트 | 용도 | 출력 |
|---|---|---|
| `compare_chamgo.py` | 쓸자료/별표 ↔ API 대조 | `검토자료/_API검토_참고자료.md` |
| `compare_waste.py` | 검토사항 ↔ API 대조 | `검토자료/_API검토_검토사항.md` |
| `build_definitions.py` | md자료/ + 쓸자료/definitions.json 빌드 | 양 폴더에 산출 |

API 캐시는 `d:/tmp/law_*.json`. 갱신하려면 먼저 `seodaeri-lambda/tools/law_api.py` 로 fetch.

### 보완자료_원본/
다른 포맷(하이센스, 동도서)에서 복사한 별표·법령 원문 텍스트. 검토 시 참고자료/별표 와 대조해 텍스트 무결성 확인용.

### 운영문서/
- 적합성확인 제도 운영 가이드라인 (2025.4)
- 폐기물처리업 허가 등에 관한 업무처리지침 (예규 제4호, 2025.11.5)

사람이 분석할 때 참고. 시스템에 직접 들어가지 않지만 LLM 프롬프트에 컨텍스트로 첨부 가능.

### 대조 리포트
- `_API검토_검토사항.md` — 검토사항 12개 파일 ↔ API 차이
- `_API검토_참고자료.md` — 쓸자료/별표 13개 ↔ API 차이 (현재 모두 ✅)

### 이력
- `_원본정리_적용내역.md` — parser 보강·데이터 정정 이력
- `파싱오류_수정결과.txt`, `파싱오류_스캔결과.txt` — 과거 파싱 정합성 점검 기록

## 작업 흐름

```
1. (검토 대상 변경) law_api.py 로 API 재조회 → d:/tmp/law_*.json
2. 도구/compare_*.py 실행 → _API검토_*.md 생성
3. _API검토_*.md 의 [ ] 항목별 수정/확인/무시 결정
4. 사용자 지시 따라 쓸자료/별표/ 또는 검토사항/ 수정
5. 변경이 있으면 도구/build_definitions.py 재실행
```
