## 처리 방법

각 차이 항목 `[ ]` 에:
- `[수정]` — API 쪽이 정답 → 참고자료 JSON 수정
- `[추가]` — API 항목이 누락 → 참고자료에 항목 추가
- `[유지]` — 참고자료가 의도된 가공 → 그대로
- `[무시]` — 형식 차이 등 무의미
- 빈칸 — 미결정

**상태 종류:**
- 🟡 다름 — 텍스트가 다름 (용어 차이일 가능성)
- 🔵 세분화부족 — API 에는 있고 참고자료에는 없음 → 추가 후보
- 🔴 원문누락 — 참고자료에는 있고 API 에는 없음 → 삭제·이전 가능성
